    Conexión con GitHub

    Sin conectar

    Para que cada ficha tenga un link corto, vista previa en WhatsApp y se pueda editar después, el panel guarda las fichas en tu repositorio de GitHub (el mismo donde está esta página). Solo necesita un permiso que creás vos, una vez.

      ¿Cómo creo el token? (2 minutos)
      1. Abrí github.com/settings/personal-access-tokens/new (te pide iniciar sesión si hace falta).
      2. Token name: Fichas. Expiration: 1 año (o "No expiration" si te lo deja elegir).
      3. Repository access: elegí Only select repositories y marcá solo el repositorio de las fichas.
      4. Permissions → Repository permissions → Contents: cambialo a Read and write. No hace falta nada más.
      5. Tocá Generate token, copiá el código que empieza con github_pat_ y pegalo arriba.

      El token queda guardado solo en este navegador y solo se usa para hablar con GitHub. Si algún día lo querés anular, borralo desde esa misma pantalla de GitHub.

      WhatsApp de la inmobiliaria

      Con código de país, sin espacios ni signos: 54 + 9 + código de área + número. Se usa en las fichas que publiques de ahora en adelante (para cambiarlo en las anteriores, editalas y guardá).

      Copia de seguridad

      La lista de fichas, las etiquetas y tus clientes (con lo que buscan y su historial de propiedades) viven en este navegador. Descargá una copia por si cambiás de celular o borrás los datos del navegador.

      Avanzado

      Usar mi propio lector de links (más estable)

      Por defecto los links se leen con servicios gratuitos de terceros. Con un "Worker" propio de Cloudflare (gratis, 5 minutos) queda más estable:

      1. Entrá a dash.cloudflare.com → Workers y Pages → Crear → Hello World → Implementar.
      2. Tocá Editar código, borrá todo, pegá el código de abajo y tocá Implementar.
      3. Copiá la dirección que termina en .workers.dev y pegala acá.
